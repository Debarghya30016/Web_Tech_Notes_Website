1. Introduction to JavaScript

JavaScript is a lightweight, interpreted programming language mainly used to make web pages interactive and dynamic. It was developed by Brendan Eich in 1995. JavaScript works with HTML and CSS to create interactive websites.

HTML provides the structure of a webpage, CSS controls its appearance, and JavaScript adds functionality such as animations, form validation, button clicks, and dynamic content updates.

Features of JavaScript

  1. Lightweight: JavaScript requires fewer resources and is easy to execute.
  2. Interpreted: It can be executed directly by a JavaScript engine.
  3. Dynamic: It allows webpage content to change without reloading the page.
  4. Object-Based: It supports objects and object-oriented programming concepts.
  5. Platform Independent: It runs on different operating systems and browsers.
  6. Event-Driven: It can respond to user actions such as clicks, typing, and mouse movements.

Uses of JavaScript

  • Creating interactive web pages.
  • Validating user input in forms.
  • Creating animations and visual effects.
  • Updating webpage content dynamically.
  • Developing web applications and games.

Example of JavaScript

<html>
<body>
    <h2>JavaScript Example</h2>
    <button onclick="alert('Hello World')">
        Click Me
    </button>
</body>
</html>

2. Objects in JavaScript

An object in JavaScript is a collection of related data and functions stored as properties and methods. Properties represent the characteristics of an object, while methods represent the actions that an object can perform.

JavaScript objects are commonly created using curly braces {} and store information in key-value pairs.

Creating an Object

let student = {
    name: "Rahul",
    age: 20,
    course: "BCA",

    display: function() {
        return this.name;
    }
};

console.log(student.name);
console.log(student.age);
console.log(student.display());

Types of Object Properties

  • Properties: Store information about an object.
  • Methods: Functions defined inside an object.

Ways to Create Objects

  1. Object Literal: Creating an object using curly braces.
  2. Using new Object(): Creating an object using the built-in Object constructor.
  3. Constructor Function: Creating multiple objects using a constructor function.
  4. Object.create(): Creating a new object with a specified prototype.

Advantages of Objects

  • Organize related data in one place.
  • Improve code reusability.
  • Make programs easier to manage.
  • Support object-oriented programming.

3. Dynamic HTML with JavaScript

Dynamic HTML (DHTML) is a combination of HTML, CSS, JavaScript, and the DOM (Document Object Model) used to create interactive and dynamic web pages. It allows webpage content, structure, and style to change without reloading the entire page.

JavaScript plays an important role in DHTML by responding to user events and modifying HTML elements and CSS properties dynamically.

Main Components of DHTML

  1. HTML: Provides the basic structure of a webpage.
  2. CSS: Controls the design, layout, and appearance.
  3. JavaScript: Adds interactivity and dynamic functionality.
  4. DOM: Allows JavaScript to access and modify webpage elements.

Features of DHTML

  • Changes webpage content dynamically.
  • Provides animations and visual effects.
  • Responds to user actions and events.
  • Changes the style of webpage elements.
  • Reduces the need for complete page reloading.

Example of DHTML

<html>
<body>

<p id="demo">Welcome to JavaScript</p>

<button onclick="changeText()">
    Change Text
</button>

<script>
function changeText() {
    document.getElementById("demo").innerHTML =
    "Content Changed Dynamically!";
}
</script>

</body>
</html>

4. Lists in JavaScript and HTML

Lists are used to display related items in an organized manner on a webpage. HTML provides different types of lists, and JavaScript can be used to create, modify, and update list items dynamically.

Types of HTML Lists

  1. Ordered List: Displays items in a numbered or alphabetical sequence using the <ol> tag.
  2. Unordered List: Displays items using bullets through the <ul> tag.
  3. Description List: Displays terms and their descriptions using <dl>, <dt>, and <dd> tags.

Example of Lists

<h3>Programming Languages</h3>

<ul>
    <li>Java</li>
    <li>Python</li>
    <li>JavaScript</li>
</ul>

<ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>

Dynamic List Using JavaScript

JavaScript can add new items to an existing list using DOM methods such as createElement() and appendChild().

<ul id="myList">
    <li>Java</li>
</ul>

<button onclick="addItem()">Add Item</button>

<script>
function addItem() {
    let item = document.createElement("li");
    item.textContent = "Python";
    document.getElementById("myList").appendChild(item);
}
</script>

5. Tables in JavaScript and HTML

HTML tables are used to display data in rows and columns. They are useful for presenting information such as student records, marks, employee details, and product information. JavaScript can dynamically create, update, and delete table rows and cells.

Important Table Tags

  • <table>: Defines a table.
  • <tr>: Defines a table row.
  • <th>: Defines a table heading.
  • <td>: Defines a table cell.
  • <thead>: Groups the header content.
  • <tbody>: Groups the main table content.
  • <tfoot>: Groups the footer content.

Example of HTML Table

<table border="1">
    <tr>
        <th>Name</th>
        <th>Age</th>
    </tr>
    <tr>
        <td>Rahul</td>
        <td>20</td>
    </tr>
    <tr>
        <td>Aman</td>
        <td>21</td>
    </tr>
</table>

Uses of JavaScript with Tables

  • Adding new rows and columns.
  • Updating existing table data.
  • Deleting table rows.
  • Sorting and filtering information.
  • Validating table data.

6. Images in JavaScript and HTML

Images are an important part of web pages because they make content more attractive and understandable. HTML uses the <img> tag to display images, while JavaScript can dynamically change image sources, dimensions, and visibility.

Important Image Attributes

  • src: Specifies the path or URL of the image.
  • alt: Provides alternative text if the image cannot load.
  • width: Sets the width of an image.
  • height: Sets the height of an image.

Example of HTML Image

<img src="image.jpg"
     alt="Sample Image"
     width="300"
     height="200">

Changing Images Using JavaScript

JavaScript can change an image dynamically by modifying its src property.

<img id="photo" src="image1.jpg" width="200">

<button onclick="changeImage()">
    Change Image
</button>

<script>
function changeImage() {
    document.getElementById("photo").src =
    "image2.jpg";
}
</script>

7. Forms in JavaScript and HTML

HTML forms are used to collect information from users, such as names, email addresses, passwords, feedback, and other details. JavaScript is used to validate user input and handle form submission.

Important HTML Form Elements

  • <form>: Defines an HTML form.
  • <input>: Creates input fields.
  • <label>: Defines labels for form controls.
  • <textarea>: Creates a multi-line text field.
  • <select>: Creates a dropdown list.
  • <option>: Defines dropdown options.
  • <button>: Creates a clickable button.

Common Input Types

  • Text
  • Password
  • Email
  • Number
  • Radio
  • Checkbox
  • Date
  • Submit

Example of HTML Form

<form>
    <label>Name:</label>
    <input type="text" id="name">

    <label>Email:</label>
    <input type="email" id="email">

    <button type="button"
    onclick="showMessage()">
        Submit
    </button>
</form>

<script>
function showMessage() {
    alert("Form Submitted Successfully!");
}
</script>

Form Validation Using JavaScript

Form validation is the process of checking whether the information entered by a user is correct and complete before submitting it. JavaScript can validate required fields, email formats, passwords, and other input values.

Advantages of Form Validation

  • Prevents incomplete information.
  • Reduces incorrect user input.
  • Improves data quality.
  • Provides immediate feedback to users.

8. Frames in HTML

Frames were used in older HTML versions to divide a browser window into multiple independent sections, where each section could display a different HTML document. They allowed users to view multiple pages within the same browser window.

Types of Frames

  1. Frameset: Divides the browser window into multiple frames.
  2. Inline Frame (iframe): Displays another webpage or document inside the current webpage.

Important Frame Tags

  • <frameset>: Defines the layout of multiple frames in older HTML.
  • <frame>: Defines an individual frame in older HTML.
  • <iframe>: Embeds another webpage within the current page.

Example of Iframe

<iframe
    src="https://example.com"
    width="500"
    height="300"
    title="Example Website">
</iframe>

Advantages of Frames

  • Allow multiple documents to be displayed together.
  • Can display external content inside a webpage.
  • Useful for embedding maps, videos, and other websites.

Note: The old <frameset> and <frame> elements are obsolete in HTML5. The <iframe> element is still supported.

9. CSS (Cascading Style Sheets)

CSS is a stylesheet language used to control the appearance and layout of HTML documents. It defines how webpage elements should look, including their colors, fonts, sizes, spacing, borders, and positioning.

CSS separates the presentation of a webpage from its structure, making websites easier to design, maintain, and update.

Types of CSS

  1. Inline CSS: CSS is written directly inside an HTML element using the style attribute.
  2. Internal CSS: CSS is written inside the <style> tag in the HTML document's head section.
  3. External CSS: CSS is written in a separate .css file and linked to the HTML document.

Example of CSS

<html>
<head>
<style>
    h1 {
        color: blue;
        text-align: center;
    }

    p {
        font-size: 18px;
    }
</style>
</head>
<body>
    <h1>Welcome</h1>
    <p>This is a styled webpage.</p>
</body>
</html>

Advantages of CSS

  • Improves the appearance of websites.
  • Separates content from presentation.
  • Reduces repeated styling code.
  • Makes website maintenance easier.
  • Supports responsive web design.

10. Document Type Definition (DTD)

DTD stands for Document Type Definition. It defines the legal structure, elements, attributes, and rules of an XML document. It specifies which elements can appear in a document, their order, and how they are related to each other.

DTD is used to ensure that an XML document follows a predefined structure and is properly organized.

Types of DTD

  1. Internal DTD: Defined directly inside an XML document.
  2. External DTD: Stored in a separate file and linked to an XML document.

Example of Internal DTD

<?xml version="1.0"?>

<!DOCTYPE student [
    <!ELEMENT student (name, age)>
    <!ELEMENT name (#PCDATA)>
    <!ELEMENT age (#PCDATA)>
]>

<student>
    <name>Rahul</name>
    <age>20</age>
</student>

Advantages of DTD

  • Defines the structure of XML documents.
  • Ensures consistency in XML data.
  • Helps validate XML documents.
  • Defines permitted elements and attributes.

11. Dynamic HTML (DHTML)

Dynamic HTML (DHTML) is a combination of HTML, CSS, JavaScript, and DOM that makes web pages interactive and dynamic. It allows developers to change webpage content, style, and structure without reloading the complete page.

Unlike static HTML pages, DHTML pages can respond to user actions such as clicking buttons, moving the mouse, and entering information.

Components of DHTML

  1. HTML: Provides webpage structure.
  2. CSS: Controls webpage design and layout.
  3. JavaScript: Adds dynamic behavior and interactivity.
  4. DOM: Allows access and modification of webpage elements.

Applications of DHTML

  • Interactive menus and navigation bars.
  • Animations and visual effects.
  • Dynamic forms and validation.
  • Interactive games and applications.
  • Changing webpage content without refreshing the page.

Advantages of DHTML

  • Improves user interaction.
  • Makes websites more attractive.
  • Provides dynamic content updates.
  • Reduces unnecessary page reloads.

12. XML Schemas

XML Schema, also known as XSD (XML Schema Definition), is used to define the structure, elements, attributes, and data types of an XML document. It specifies the rules that an XML document must follow to be considered valid.

Unlike DTD, XML Schema supports different data types such as string, integer, decimal, date, and Boolean. It is written using XML syntax.

Features of XML Schema

  1. Defines the structure of XML documents.
  2. Supports built-in data types such as string, integer, and date.
  3. Allows creation of custom data types.
  4. Supports namespaces.
  5. Defines the number and order of elements.
  6. Provides strong data validation.

Example of XML Schema

<xs:schema xmlns:xs=
"http://www.w3.org/2001/XMLSchema">

    <xs:element name="student">
        <xs:complexType>
            <xs:sequence>

                <xs:element name="name"
                type="xs:string"/>

                <xs:element name="age"
                type="xs:integer"/>

            </xs:sequence>
        </xs:complexType>
    </xs:element>

</xs:schema>

Advantages of XML Schema

  • Provides accurate data validation.
  • Supports different data types.
  • Allows reusable data definitions.
  • Helps maintain consistency in XML documents.

13. Object Models (DOM)

DOM stands for Document Object Model. It is a programming interface that represents an HTML or XML document as a tree structure of objects. It allows programming languages such as JavaScript to access, modify, add, and delete elements and content of a webpage.

In DOM, every element, attribute, and text in a document is represented as a node. JavaScript uses DOM methods to interact with these nodes.

Structure of DOM

A DOM tree contains different types of nodes:

  • Document Node: Represents the complete document.
  • Element Node: Represents HTML or XML elements.
  • Attribute Node: Represents element attributes.
  • Text Node: Represents text inside elements.

Important DOM Methods

  • getElementById(): Selects an element using its ID.
  • getElementsByClassName(): Selects elements using a class name.
  • getElementsByTagName(): Selects elements using a tag name.
  • querySelector(): Selects the first element matching a CSS selector.
  • createElement(): Creates a new element.
  • appendChild(): Adds a child node.
  • removeChild(): Removes a child node.

Example of DOM

<html>
<body>

<p id="demo">Hello World</p>

<button onclick="changeText()">
    Change Text
</button>

<script>
function changeText() {
    document.getElementById("demo").innerHTML =
    "DOM Modified Successfully!";
}
</script>

</body>
</html>

Advantages of DOM

  • Allows dynamic modification of webpages.
  • Provides easy access to document elements.
  • Supports event handling.
  • Helps create interactive web applications.

14. Presenting XML

XML stands for Extensible Markup Language. It is a markup language used to store, organize, and transport structured data. XML allows users to create their own tags according to their requirements.

XML focuses on storing and describing data rather than displaying it. It is commonly used for data exchange between different applications and systems.

Features of XML

  1. Extensible: Users can create their own tags.
  2. Platform Independent: XML works across different operating systems and applications.
  3. Self-Descriptive: Tags describe the meaning of the stored data.
  4. Structured: Data is organized in a hierarchical format.
  5. Readable: XML documents can be read by humans and machines.

Example of XML Document

<?xml version="1.0"?>

<student>
    <name>Rahul</name>
    <age>20</age>
    <course>BCA</course>
</student>

Ways of Presenting XML

  1. CSS: XML data can be styled using CSS to control its appearance.
  2. XSLT: Extensible Stylesheet Language Transformations converts XML data into formats such as HTML or another XML document.
  3. XSL-FO: Used to format XML data for printed documents and PDF output.

Applications of XML

  • Data exchange between applications.
  • Web services and APIs.
  • Configuration files.
  • Document storage and data management.
  • Information sharing between different systems.

15. Using XML Processors: DOM and SAX

XML processors are software tools used to read, interpret, and process XML documents. They help applications access and extract information from XML files. Two commonly used XML processing methods are DOM (Document Object Model) and SAX (Simple API for XML).

A. DOM (Document Object Model)

DOM is an XML processing method that loads the entire XML document into memory and represents it as a tree structure. Each element, attribute, and text value is stored as a node. Applications can access, modify, add, or delete nodes as required.

Features of DOM

  • Loads the complete XML document into memory.
  • Represents data in a tree structure.
  • Allows random access to different elements.
  • Supports modification of XML content.
  • Suitable for small and medium-sized XML documents.

B. SAX (Simple API for XML)

SAX is an event-based XML processing method that reads an XML document sequentially from beginning to end. Instead of loading the entire document into memory, it generates events whenever it encounters elements, text, or other XML components.

Features of SAX

  • Processes XML documents sequentially.
  • Does not load the entire document into memory.
  • Uses events to process XML data.
  • Consumes less memory compared to DOM.
  • Suitable for large XML documents.

Difference Between DOM and SAX

DOM SAX
Tree-based processing. Event-based processing.
Loads the entire document into memory. Reads the document sequentially.
Requires more memory. Requires less memory.
Allows random access to elements. Provides sequential access.
Supports modifying document content. Primarily used for reading and processing data.
Suitable for smaller XML files. Suitable for large XML files.
