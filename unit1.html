1. History of the Internet

The Internet is a worldwide network of interconnected computers that allows users to communicate, exchange information, and access resources from anywhere in the world.

The development of the Internet started in the 1960s when the United States Department of Defense introduced a research project called ARPANET (Advanced Research Projects Agency Network).

Important Developments

  • 1969: ARPANET was established, connecting four universities in the USA.
  • 1971: Ray Tomlinson developed the first network email system.
  • 1973: Vinton Cerf and Robert Kahn started developing TCP/IP protocols.
  • 1983: ARPANET officially adopted TCP/IP protocols.
  • 1989: Tim Berners-Lee proposed the World Wide Web.
  • 1991: The World Wide Web became publicly available.
  • 1993: The Mosaic web browser was introduced.
  • 1995: Internet services were introduced to the public in India by VSNL.
  • 2016: Reliance Jio introduced affordable 4G services in India.
  • 2022: 5G services were officially launched in India.

Today, the Internet is widely used in education, business, communication, banking, entertainment, and research.

2. World Wide Web (WWW)

The World Wide Web (WWW) is a collection of interconnected web pages and websites that can be accessed through the Internet using a web browser. It was invented by Tim Berners-Lee in 1989 at CERN (European Organization for Nuclear Research).

The WWW allows users to access and share information in different forms, such as text, images, audio, videos, and hyperlinks. It works on a client-server model in which a web browser sends requests to a web server, and the server returns the requested information.

Main Components of WWW

  1. Web Pages: Documents containing information displayed in a browser.
  2. Website: A collection of related web pages.
  3. Web Browser: Software used to access websites.
  4. Web Server: Stores and delivers web pages.
  5. URL: Address used to locate a resource on the Web.
  6. Hyperlinks: Clickable links that connect different web pages.

Uses of WWW

  • Online education and learning.
  • Online shopping and banking.
  • Communication and social networking.
  • Information sharing and research.
  • Entertainment and digital media.

3. HTML (HyperText Markup Language)

HTML is the standard markup language used to create and structure web pages. It describes how content should be displayed in a web browser using different tags and elements.

HTML was introduced by Tim Berners-Lee in 1991. It is the foundation of web development and is used to create headings, paragraphs, images, tables, lists, forms, and hyperlinks.

Basic Structure of an HTML Document

<!DOCTYPE html>
<html>
<head>
    <title>My First Page</title>
</head>
<body>
    <h1>Welcome</h1>
    <p>This is my webpage.</p>
</body>
</html>

Main Features of HTML

  1. It is easy to learn and use.
  2. It is platform-independent.
  3. It supports images, audio, and videos.
  4. It allows linking between web pages.
  5. It works with CSS and JavaScript.

Important HTML Tags

  • <html> – Defines an HTML document.
  • <head> – Contains page information.
  • <title> – Defines the page title.
  • <body> – Contains visible webpage content.
  • <h1> – Defines a heading.
  • <p> – Defines a paragraph.
  • <a> – Creates a hyperlink.
  • <img> – Displays an image.

4. HTTP (HyperText Transfer Protocol)

HTTP is an application-layer protocol used for communication between web browsers and web servers. It is the foundation of data communication on the World Wide Web.

HTTP follows a request-response model. When a user enters a website address in a browser, the browser sends an HTTP request to the web server. The server processes the request and sends an HTTP response containing the requested webpage or resource.

Working of HTTP

  1. The user enters a URL in the web browser.
  2. The browser sends a request to the web server.
  3. The server processes the request.
  4. The server sends a response to the browser.
  5. The browser displays the requested webpage.

Common HTTP Methods

  • GET: Retrieves data from a server.
  • POST: Sends data to a server.
  • PUT: Updates or replaces existing data.
  • DELETE: Deletes specified data.

HTTP Status Codes

  • 200: OK (Request successful).
  • 301: Moved Permanently.
  • 400: Bad Request.
  • 404: Not Found.
  • 500: Internal Server Error.

HTTP vs HTTPS: HTTPS is the secure version of HTTP. It uses SSL/TLS encryption to protect information exchanged between browsers and servers.

5. SMTP (Simple Mail Transfer Protocol)

SMTP is an application-layer protocol used to send emails over the Internet. It helps transfer email messages from the sender's email client to a mail server and between different mail servers.

SMTP is mainly responsible for sending and forwarding emails. It works with receiving protocols like POP3 and IMAP.

Working of SMTP

  1. The sender writes an email using an email application.
  2. The email application sends the message to the SMTP server.
  3. The SMTP server identifies the recipient's mail server.
  4. The message is transferred to the recipient's mail server.
  5. The recipient accesses the email using POP3 or IMAP.

Common SMTP Ports

  • Port 25: Traditional SMTP communication.
  • Port 465: SMTP with implicit SSL/TLS.
  • Port 587: Email submission with STARTTLS.

Features of SMTP

  1. Used for sending emails.
  2. Supports email transfer between mail servers.
  3. Supports text-based email communication.
  4. Can work with MIME to send multimedia attachments.
  5. Provides reliable email transfer through TCP.

6. POP3 (Post Office Protocol Version 3)

POP3 is an application-layer protocol used to receive and download emails from a mail server to a user's local device. It allows users to read downloaded emails without an active Internet connection.

POP3 generally downloads emails from the server and may remove them from the server after downloading, depending on the configuration.

Working of POP3

  1. The user opens an email application.
  2. The application connects to the POP3 mail server.
  3. The user is authenticated using login credentials.
  4. Emails are downloaded from the server to the device.
  5. The user can read downloaded emails offline.

Common POP3 Ports

  • Port 110: Standard POP3.
  • Port 995: Secure POP3 using SSL/TLS.

Features of POP3

  1. Downloads emails to the local device.
  2. Allows offline email access.
  3. Simple and easy to configure.
  4. Uses less server storage when emails are removed after downloading.
  5. Does not provide automatic synchronization across multiple devices like IMAP.

7. MIME (Multipurpose Internet Mail Extensions)

MIME is an Internet standard that extends the basic email format to support different types of content. Originally, email systems mainly supported plain text. MIME was introduced to allow users to send images, audio, videos, documents, and other multimedia files through email.

MIME works with email protocols such as SMTP to transfer different types of email content.

Main Features of MIME

  1. Supports email attachments such as PDF, images, and documents.
  2. Allows sending audio and video files.
  3. Supports different languages and character sets.
  4. Supports HTML-formatted emails.
  5. Identifies the type and format of email content.

Important MIME Headers

  • MIME-Version: Specifies the MIME version.
  • Content-Type: Identifies the type of content, such as text, image, or audio.
  • Content-Transfer-Encoding: Specifies how the content is encoded for transmission.
  • Content-Disposition: Specifies whether content should be displayed or downloaded as an attachment.

Example: When a user sends an email containing a PDF file, MIME helps identify and encode the attachment so that it can be transferred and understood by the receiving email system.

8. IMAP (Internet Message Access Protocol)

IMAP is an application-layer protocol used to access and manage emails directly from a mail server. Unlike POP3, IMAP generally keeps emails stored on the server and synchronizes them across multiple devices.

It allows users to read, organize, delete, and search emails without downloading all messages permanently to their local devices.

Working of IMAP

  1. The user opens an email application.
  2. The application connects to the IMAP server.
  3. The user logs in using their email credentials.
  4. The application displays emails stored on the server.
  5. Any changes made, such as reading or deleting emails, are synchronized across connected devices.

Common IMAP Ports

  • Port 143: Standard IMAP.
  • Port 993: Secure IMAP using SSL/TLS.

Features of IMAP

  1. Stores emails on the mail server.
  2. Synchronizes emails across multiple devices.
  3. Allows users to organize emails into folders.
  4. Supports searching and managing emails.
  5. Provides access to emails from different locations.

Difference Between POP3 and IMAP

  • POP3 downloads emails to a local device.
  • IMAP keeps emails on the server.
  • POP3 is suitable for offline access.
  • IMAP is suitable for accessing emails across multiple devices.

9. DNS (Domain Name System)

DNS stands for Domain Name System. It is a naming system that translates human-readable domain names into IP addresses so that computers can locate websites and communicate with servers.

For example, when a user enters www.google.com in a browser, the DNS server finds the corresponding IP address of the website's server.

DNS is also known as the phonebook of the Internet because it converts easy-to-remember domain names into numerical IP addresses.

Working of DNS

  1. The user enters a domain name in the browser.
  2. The browser checks its local DNS cache.
  3. If the address is not available, a DNS query is sent to a DNS resolver.
  4. The resolver finds the IP address by querying the required DNS servers.
  5. The IP address is returned to the browser.
  6. The browser connects to the website's server.

Types of DNS Servers

  1. DNS Resolver: Receives DNS queries from users and finds the required IP address.
  2. Root DNS Server: Directs queries to the appropriate top-level domain server.
  3. TLD Server: Handles domain extensions such as .com, .org, and .in.
  4. Authoritative DNS Server: Provides the actual DNS records for a domain.

Common DNS Records

  • A Record: Maps a domain to an IPv4 address.
  • AAAA Record: Maps a domain to an IPv6 address.
  • MX Record: Specifies mail servers for a domain.
  • CNAME Record: Creates an alias for another domain name.
  • NS Record: Identifies authoritative name servers.

DNS commonly uses port 53 and supports both UDP and TCP.

10. Web Browsers

A web browser is a software application used to access, retrieve, and display information available on the World Wide Web. It allows users to open websites, view web pages, download files, and interact with online services.

When a user enters a URL, the browser sends a request to the web server and receives the required webpage. It then interprets HTML, CSS, and JavaScript to display the content properly.

Examples of Web Browsers

  1. Google Chrome
  2. Mozilla Firefox
  3. Microsoft Edge
  4. Apple Safari
  5. Opera

Main Features of Web Browsers

  1. Address Bar: Used to enter website URLs.
  2. Navigation Buttons: Provide back, forward, and refresh options.
  3. Bookmarks: Save frequently visited websites.
  4. History: Stores records of visited websites.
  5. Tabs: Allow multiple webpages to be opened simultaneously.
  6. Download Manager: Manages downloaded files.
  7. Privacy and Security: Provides features such as private browsing and protection against unsafe websites.

Functions of Web Browsers

  • Access websites and online information.
  • Display text, images, audio, and videos.
  • Execute JavaScript programs.
  • Download and upload files.
  • Support online applications and services.

11. Web Servers

A web server is a computer system or software that stores, processes, and delivers web pages to users through the Internet. It receives requests from web browsers and sends the required resources using HTTP or HTTPS protocols.

A web server can host websites, images, videos, documents, and other online resources.

Working of a Web Server

  1. A user enters a website URL in a browser.
  2. The browser sends an HTTP or HTTPS request to the web server.
  3. The web server receives and processes the request.
  4. It locates the requested webpage or resource.
  5. The server sends an HTTP response to the browser.
  6. The browser displays the webpage to the user.

Types of Web Servers

  1. Apache HTTP Server: An open-source web server widely used for hosting websites.
  2. Nginx: A high-performance web server used for handling multiple requests efficiently.
  3. Microsoft IIS: A web server developed by Microsoft for Windows-based systems.

Functions of Web Servers

  • Store and host website files.
  • Process client requests.
  • Deliver web pages and other resources.
  • Support HTTP and HTTPS communication.
  • Provide security and access control.
  • Maintain server logs and handle multiple users.
